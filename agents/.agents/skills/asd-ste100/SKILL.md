# ASD-STE100 Simplified Technical English

Write user-facing text so that a reader can parse each sentence in one pass.
STE removes two causes of error: words with more than one meaning, and sentences with more than one structure.

This skill gives the writing rules that you can apply without the official dictionary.
It does not copy the ASD word list. Get the specification from https://www.asd-ste100.org when a document must match the dictionary word for word.

## Scope

Apply STE to replies, documentation, procedures, reports, and error messages.

Do not apply STE to:

- Source code and comments that must match repository style
- Identifiers, commands, file paths, and quoted text
- Official names of products, parts, and documents

If the user asks for a different style, obey the user.

## Classify the text

Before you write, classify each part:

- **Procedure**: tells the reader to do a task. Use the imperative. Limit: 20 words per sentence.
- **Description**: gives information. Do not use the imperative. Limit: 25 words per sentence.

Do not mix the two types in one paragraph.

## Sentence rules

- Write one instruction or one topic in each sentence.
- Two actions in one sentence are permitted only when they occur at the same time.
- Keep the subject, the verb, the article, and the word "that". Write "Make sure that the file exists."
- Do not use contractions. Write "do not", not "don't".
- Do not use semicolons. Write two sentences.
- Use a vertical list when a sentence must hold many items or steps.
- Limit each paragraph to one topic and six sentences.
- Put a condition before a command, and put a comma after the condition. "If the light comes on, stop the process."

## Verb rules

- Use these verb forms only: infinitive, imperative, simple present, simple past, future with "will", and past participle as an adjective.
- Do not use the "-ing" form of a verb unless it is part of a technical name.
- Do not use a helping verb with a past participle. Write "The operator adjusted the linkage."
- Use the active voice. Write "A relay connects the circuits."
- Use only "can", "must", and "will" as helping verbs. Do not use "should", "would", "may", "might", or "shall".
- Keep a hedge when it is part of the meaning. Do not change "The request may have failed" into "The request failed."

## Word rules

- Use one short word for one meaning. Do not rotate synonyms for the same item or action.
- Use a word as one part of speech in the full text. Prefer the noun form when a word is both a noun and a verb. Write "Do a test of the system", not "Test the system", when "test" is the noun.
- Use a verb for an action. Write "Analyze the log", not "Do an analysis of the log."
- Limit noun clusters to three words. Break longer clusters with "of", "on", "in", or "for".
- Do not use phrasal verbs. Write "Remove the panel", not "Take off the panel."
- Do not use vague words. Write the quantity, the name, or the action.
- Use American English spelling.
- Keep technical names. Define a technical name once if it is not common English.

## After you write

Scan the text and correct each error:

1. Remove semicolons and contractions.
2. Replace "has/have/had" + past participle with the simple past, unless the compound form is necessary for meaning.
3. Replace "should", "would", "may", "might", and "shall", unless the word is a hedge that you must keep.
4. Rewrite unapproved "-ing" verbs.
5. Make the agent the subject, or use the imperative.
6. Divide sentences and paragraphs that are too long.
7. Use one name for each item in the full text.

Do not add facts. Do not remove a condition, a quantity, or a warning to make a sentence shorter.
