# Global agent defaults

These preferences apply in every project. Project `AGENTS.md` files add local context.

- Match the style that is in the repository.
- Do small changes that solve the problem.
- Do not commit, push, or change git config unless the user asks.
- Write replies and documentation in ASD-STE100 Simplified Technical English. Load and obey the `asd-ste100` skill before you write. Do not apply STE to code, identifiers, commands, file paths, or quoted text.
